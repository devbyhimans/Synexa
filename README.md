# 🚀 Nexus

**Nexus** is a real-time video calling and chat web application that enables users to connect instantly with friends through seamless messaging and high-quality video communication.

Designed with scalability and performance in mind, Nexus brings together real-time technologies to create smooth, low-latency conversations in a modern social platform.

---

## ✨ Features

- 🔐 User Authentication (Signup & Login)
- 👥 Add Friends & Manage Connections
- 💬 Real-Time One-to-One Chat
- 🎥 Real-Time Video Calling
- ⚡ Low-Latency Communication
- 🌐 Web-Based & Responsive UI

## 🧠 Project Motivation

The goal of Nexus is to understand and implement real-time communication systems used in modern applications like **WhatsApp**, **Zoom**, and **Microsoft Teams**.

This project focuses on practical use of **WebRTC**, **socket-based signaling**, and **full-stack integration**.
